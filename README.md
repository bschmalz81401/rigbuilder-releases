# HeadRush Rig Builder — releases

Installers and release notes for the **HeadRush Rig Builder** desktop apps: a
pair of tools that turn a plain-English description of a tone into a complete,
valid rig and push it to a HeadRush floor unit.

**Downloads and documentation live at
[rigbuilder.schmalz.rocks](https://rigbuilder.schmalz.rocks/).** The download
links there point at the releases in this repository, so you can take a build
from either place and get the same file.

## What is here

Each release carries the installers for one app version and the notes for it:

| tag | what it is |
|---|---|
| `mac-v*` | the macOS app, as a `.dmg` |
| `win-v*` | the Windows app: an installer and a portable `.exe` |

The two apps version independently, so the newest `mac-v*` and the newest
`win-v*` will not usually be the same number.

## What is not here

**No source code.** This repository exists to host published builds and their
notes, nothing else. The apps are developed in their own private repositories,
and the website has its own.

Builds are published here only after they have been through their smoke test,
so a version appearing on this page is one that was actually checked rather
than one that merely compiled.

## Reporting something

Issues are best raised wherever you got the app from. If you found a problem
with a download itself — a broken link, a file that will not open — an issue
here is the right place.
